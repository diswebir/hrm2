# 👥 سامانه جامع مدیریت منابع انسانی — HRM Pro

سامانه کامل و حرفه‌ای مدیریت منابع انسانی با **Node.js** و دیتابیس **SQLite** — مخصوص نصب آسان روی هاست‌های **cPanel**.

> 📖 **بیش از ۱۲۶ قابلیت** با آموزش شماره‌گذاری‌شده در خود سامانه: پس از نصب، منوی **«درباره سامانه»** را باز کنید.

## 🖥 نصب روی cPanel (گام‌به‌گام)

### مرحله ۱ — آپلود پروژه
1. پروژه را به‌صورت ZIP دانلود کنید.
2. وارد cPanel شوید → **File Manager**.
3. پیشنهاد: پوشه‌ای مثل `/home/USERNAME/hrmapp` بسازید (خارج از public_html) و ZIP را همان‌جا Extract کنید.
   - اگر می‌خواهید مستقیم روی دامنه اصلی باشد، مشکلی نیست؛ cPanel خودش یک زیردامنه/مسیر به اپ وصل می‌کند.

### مرحله ۲ — ساخت اپلیکیشن Node.js
1. در cPanel بخش **Software** → **Setup Node.js App** را باز کنید.
2. روی **Create Application** بزنید:
   - **Node.js version**: نسخه ۱۶ یا بالاتر (پیشنهادی: ۱۸ یا ۲۰)
   - **Application mode**: Production
   - **Application root**: مسیر پوشه پروژه (مثلاً `hrmapp`)
   - **Application URL**: دامنه یا زیردامنه موردنظر
   - **Application startup file**: `app.js`  ⬅️ مهم!
3. **Create** را بزنید.

### مرحله ۳ — نصب پکیج‌ها
1. در همان صفحه، دکمه **Run NPM Install** را بزنید و صبر کنید (۱ تا ۲ دقیقه).
   - همه وابستگی‌ها **خالص جاوااسکریپت** هستند و نیاز به کامپایل ندارند.

### مرحله ۴ — اجرا و نصب
1. دکمه **Restart** را بزنید.
2. آدرس دامنه را در مرورگر باز کنید → به‌صورت خودکار به **نصب‌کننده** هدایت می‌شوید:
   - مرحله ۱: بررسی خودکار پیش‌نیازها (همه باید سبز شوند)
   - مرحله ۲: نام شرکت + ساخت حساب مدیر (نام کاربری انگلیسی + رمز)
   - تیک **«ایجاد داده‌های نمونه»** را بزنید تا با اطلاعات آزمایشی آشنا شوید.
3. تمام! 🎉 وارد سامانه شوید.

> 🔁 **نکته مهم cPanel:** بعد از هر تغییر در تنظیمات SMTP یا بازیابی پشتیبان، از صفحه Node.js App یک‌بار **Restart** بزنید.

## 📂 ساختار پروژه

```
├── app.js              ← فایل شروع (Application startup file در cPanel)
├── package.json
├── data/               ← دیتابیس (hrm.sqlite) + فایل‌های آپلودی — خودکار ساخته می‌شود
├── src/
│   ├── db.js           ← لایه دیتابیس SQLite (sql.js) با ذخیره خودکار
│   ├── schema.sql      ← اسکیمای کامل (۴۰+ جدول)
│   ├── seed.js         ← داده پایه + داده نمونه دمو
│   ├── crud.js         ← موتور CRUD عمومی
│   ├── features.js     ← کاتالوگ ۱۲۶ قابلیت (منبع صفحه درباره سامانه)
│   ├── helpers.js      ← مجوزها، اعلان‌ها، لاگ
│   ├── menu.js         ← ساختار منو بر اساس دسترسی
│   ├── sessionStore.js ← نشست‌ها در SQLite
│   ├── mailer.js       ← ایمیل اختیاری SMTP
│   └── utils.js        ← تبدیل تاریخ شمسی، اعداد فارسی، CSV و...
├── routes/             ← ۱۷ ماژول مسیریابی
├── views/              ← قالب‌های EJS
└── public/             ← CSS/JS + کتابخانه‌های محلی (بدون CDN)
```

## 🛠 رفع اشکال رایج

| مشکل | راه‌حل |
|---|---|
| صفحه «Service Unavailable» | در Setup Node.js App دکمه Restart بزنید و لاگ خطا را ببینید |
| خطا در Run NPM Install | نسخه Node را ۱۶+ انتخاب کنید و دوباره تلاش کنید |
| «پوشه data قابل نوشتن نیست» | در File Manager روی پوشه data → Permissions → مقدار `755` |
| بعد از تغییرات اعمال نمی‌شود | دکمه Restart در صفحه Node.js App |
| فراموشی رمز مدیر | صفحه ورود ← فراموشی رمز (لینک برای مدیر سامانه اعلان می‌شود) |
| انتقال به هاست جدید | فایل `data/hrm.sqlite` را کپی کنید (کل داده‌ها همان است) |

## 🔐 نکات امنیتی

- رمز حساب‌های دمو را تغییر دهید (مدیریت ← کاربران).
- برای بازیابی رمز با ایمیل، در تنظیمات SMTP را فعال کنید؛ در غیر این صورت لینک بازیابی به مدیر سیستم اعلان می‌شود.
- به‌صورت دوره‌ای از بخش **پشتیبان‌گیری** نسخه بگیرید.
- دسترسی هر نقش را در **نقش‌ها و دسترسی‌ها** مطابق سیاست سازمان تنظیم کنید.
